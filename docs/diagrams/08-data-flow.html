Data flow · funes-vision

Camera frame to retained record

A JPEG lands in a watched directory, a fast YOLO pass writes a preliminary record, and a deep LLM pass on any real detector hit merges HA flags into analysis.json. Visits are grouped into bursts.json, the gallery and API publish the catalogs, and pin-aware retention deletes empty frames at 30 days or the 5 GB cap.

Sensitive by default

  • camera frames and occupancy timing stay on the host
  • the only egress is Slack / HA MQTT, off by default
  • cloud inference is gated by the allow_cloud switch

Retention boundaries

  • Pass 1: unpinned frames older than max_age_days (30d)
  • Pass 2: timeline frames capped at persist_budget_pct (20%)
  • Pass 3: over max_dir_gb (5 GB) evicts negatives first
  • pinned frames are never deleted; deletions hit retention_log.json

Conditional enrichment

  • deep LLM runs on any detector hit that is not gate-ignored — person, dog, cat, bird, or a car sharing the frame with one
  • car-only frames are skipped as _llm_skip=no_trigger, then verified by idle backfill if enabled
  • detection entries are pruned only under disk pressure
