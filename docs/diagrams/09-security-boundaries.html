Security and trust boundaries

Three trust zones. Ingress is untrusted, the host is loopback-only, and all egress is opt-in. Authentication is enforced at nginx and at the API token.

Enforcement points

  • nginx auth_basic guards /api/ before anything reaches the process
  • Optional WEBCAM_API_TOKEN backs up the proxy for loopback callers

Least exposure by default

  • API binds 127.0.0.1:8190; CORS is an origin allowlist, never wildcard
  • Secrets are gitignored and never returned by the API

Sensitive data

  • Frames and occupancy timing stay on-box unless egress is enabled
  • Retention deletes empty frames after 30 days or 5 GB per camera
