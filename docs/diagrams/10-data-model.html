Catalog data model

The gallery state is a set of JSON catalogs on disk, not a database. images is the hub; the other collections reference it by filename — and the field lists below are transcribed from the writers, not invented.

Filename is the key

  • Every catalog is joined by the still's filename, not a surrogate id
  • analysis and pins are 1:1 with an image; bursts and inference_log are 1:N
  • Real entry shapes: bursts is {summary, images[]}, inference_log is {image, model, trigger, started, duration_s, labels, ok}, retention_log is {ts, dir, count, bytes_freed}

Recoverable writes

  • Catalogs are written atomically and recover from truncated JSON
  • pins.json is the retention exclusion list

Canonical taxonomy

  • taxonomy.py is the single source of truth for HA flags and timezone
  • Exposed to the SPA at GET /api/taxonomy
