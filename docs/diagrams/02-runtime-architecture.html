funes-vision runtime architecture

Runtime components, tiers, and trust boundaries: FTP camera ingress, host loopback services, on-disk catalog, the loopback API, the Docker gallery on the LAN, and gated outbound integrations.

Trust boundaries

  • Cameras push over FTP; pipeline holds a global flock
  • API binds loopback only; nginx adds auth_basic

Host services

  • webcam-pipeline@ runs create-index.sh + analyze_images.py
  • Ollama on localhost:11434

Egress gates

  • allow_cloud=false blocks cloud models
  • Slack, ntfy and HA MQTT are optional
