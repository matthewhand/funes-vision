Deployment · funes-vision

Single-host deployment

systemd units run the ingest pipeline, the local LLM and the write API on one host; a docker compose nginx container serves the gallery on loopback. Cameras arrive over the LAN by FTP; broker and cloud egress are optional.

Host & containers

  • systemd owns pipeline, api and ollama
  • docker compose owns the gallery; healthcheck timer every 60s
  • watchdog cron restarts stuck sweeps and forces retention

Reachability

  • 8180 / 8190 / 11434 bound to 127.0.0.1 only
  • FTP :21 inbound from the camera LAN
  • egress is opt-in and disabled by default

Placement & mounts

  • camera roots bind-mounted read-only into nginx
  • YOLO weights and models live under WEBCAM_MODELS_DIR
  • settings.json and /etc/webcam/webcam.env are host-local
