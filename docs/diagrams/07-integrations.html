Outbound integrations

Pipeline events are dispatched to three optional consumers. Everything on the left stays on the box; only the external zone leaves it.

Dispatcher is the seam

  • integrations/__init__.py fans events out; each provider is independent
  • Failure in one provider does not stop the pipeline

Only egress leaves the box

  • Slack, ntfy and MQTT are opt-in and off by default
  • Each carries image data or HA flags off-host

Secrets never sync

  • Tokens live in gitignored settings.json / integrations.json
  • GET /api/integrations returns presence flags only
