Frame ingest & background analysis

A camera FTP frame wakes create-index.sh; the analyze_images.py sweep runs retention, a YOLO fast pass, and a gemma4 deep pass only when a detector fires.

Detector gates the deep pass

  • Fast pass is YOLO yolov4-tiny (person/car/bird/cat/dog)
  • Deep pass runs gemma4:e2b only on detector hits
  • Detector labels are never overwritten by the LLM

Retention first

  • 30-day age budget, per-camera 5 GB cap
  • Pins are never deleted; detections pruned only under pressure

Catalogs

  • analysis.json, bursts.json, images.json
  • inference_log, inference_status, retention_log
