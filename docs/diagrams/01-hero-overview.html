funes-vision overview

Local-first, two-stage camera sentry: motion stills are ingested, screened by a fast detector, then captioned by a local vision LLM and served as a gallery.

Two-stage detection

  • Fast pass: YOLOv4-tiny via OpenCV DNN
  • Deep pass: local vision LLM on detector hits only

Local-first

  • Ollama on localhost, allow_cloud=false gates cloud models
  • Catalog is plain JSON on disk

Gallery + API

  • nginx serves the SPA on :8180
  • Write API on loopback :8190
